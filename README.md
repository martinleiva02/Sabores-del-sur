# Sabores del Sur

Sitio web de un restaurante de comida casera argentina, desarrollado como proyecto final del curso de Frontend de Coderhouse.

🔗 **Demo:** https://martinleiva02.github.io/Sabores-del-sur/

## Secciones
- **Inicio:** presentación del restaurante y acceso al menú.
- **Menú:** platos como pizza, milanesa y fideos.
- **Nosotros:** historia y propósito del restaurante.
- **Galería:** fotos de los platos y del lugar.
- **Contacto:** formas de comunicarse con el local.
- **Testimonios** de clientes.

## Tecnologías
HTML · CSS

## Cómo verlo en tu computadora
1. Clonar el repositorio: `git clone https://github.com/martinleiva02/Sabores-del-sur.git`
2. Abrir el archivo `index.html` en el navegador.

## Qué aprendí
- Estructurar un sitio de varias secciones con HTML.
- Dar estilo y organizar el diseño con CSS y SCSS.
- Armar un proyecto completo de principio a fin.
